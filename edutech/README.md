# EduTech — интерактивная платформа по информатике

Локальное образовательное веб-приложение на HTML, CSS и JavaScript ES modules. Серверная часть, аккаунты и внешние API не требуются.

## Запуск в VS Code

1. Распакуйте папку `edutech` и откройте её в Visual Studio Code.
2. Рекомендуемый способ: установите расширение **Live Server** (Ritwick Dey), нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.
3. Либо откройте терминал в папке проекта и запустите встроенный сервер Python: `python -m http.server 8000`. Затем откройте `http://localhost:8000`.
4. Не открывайте `index.html` напрямую через `file://`: браузер может блокировать ES-модули.

## Вход в EduTech

При открытии сайта появится форма входа:

- Логин: `admin`
- Пароль: `EduTech2026!`

Кнопка «Выйти» завершает текущую сессию. Состояние входа хранится в `sessionStorage` и сбрасывается при завершении сессии браузера.

**Важно:** это демонстрационная клиентская авторизация. Логин и пароль можно увидеть в исходном JavaScript, поэтому не используй её для реальных аккаунтов или конфиденциальных данных. Для настоящей защиты нужен сервер с проверкой пароля.

## Что реализовано

- Главная панель, адаптивная навигация и переключение тёмной/светлой темы.
- 6 модулей и 15 полноценных коротких уроков с примерами и мини-заданиями.
- 6 тестов по 10 вопросов, перемешивание вопросов/вариантов, проверка ответа, объяснения, подсчёт процента, повторное прохождение и режим на 5 минут.
- 4 лаборатории: конвертер систем счисления, логический калькулятор с таблицей истинности, конструктор ПК с учебными правилами совместимости, симуляция передачи сетевых пакетов.
- XP, уровни, достижения, учебная серия, история результатов и задание дня.
- Поиск уроков, модулей и лабораторий, фильтрация по категории и статусу.
- Локальный профиль, LocalStorage, импорт/экспорт JSON и сброс с подтверждением.
- Семантические элементы, видимый фокус клавиатуры и поддержка `prefers-reduced-motion`.

## Ограничения

- Данные хранятся только в текущем браузере и не синхронизируются между устройствами. LocalStorage не является защищённой системой учётных записей.
- Цены и совместимость в конструкторе ПК демонстрационные и упрощённые.
- Сетевой стенд моделирует условные пакеты, а не отправляет реальные сетевые запросы.
- Счётчик серии увеличивается при учебной активности в разные календарные дни; пропущенные дни сбрасывают серию.
- Внешние API и обязательные библиотеки не используются.

## Проверка

Все JS-файлы проверены командой `node --check`. Дополнительно вручную проверьте навигацию, прохождение теста, четыре лаборатории, экспорт/импорт и адаптивность в браузере. Для проверки ошибок откройте DevTools → Console.


## Регистрация и сохранение аккаунта

На экране входа нажмите «Зарегистрироваться», заполните имя, логин и пароль (минимум 8 символов), затем создайте аккаунт. Данные аккаунта и учебный прогресс сохраняются в LocalStorage этого браузера. После выхода можно войти с тем же логином и паролем; прогресс хранится отдельно для каждого логина. Демо-вход `admin` / `EduTech2026!` также оставлен.

Это автономная учебная регистрация без сервера: данные существуют только в текущем браузере и не синхронизируются между устройствами. Хеш пароля хранится локально, однако клиентскую авторизацию можно обойти через инструменты разработчика; не используйте реальные или повторно используемые пароли. Очистка данных браузера удалит локальные аккаунты и прогресс.
